# DO NOT

Never use Bootstrap-looking layouts.

Never use Material UI style.

Never create plain white cards without hierarchy.

Never use tiny typography.

Never overuse gradients.

Never overuse borders.

Never make everything the same size.

Never create generic AI SaaS layouts.

---

# ALWAYS

Use asymmetrical composition.

Use oversized typography.

Use floating elements.

Use glass cards.

Use rounded pills.

Use premium spacing.

Use editorial layouts.

Use hand-drawn accent graphics.

Use neon accent sparingly.

Use subtle motion.

Everything should look like it belongs to one product ecosystem.

Every new component MUST look like it was designed by the same designer.

Consistency is more important than creativity.
